# 🧮 Subtraction Calculator

A simple **Subtraction Calculator** built with HTML and JavaScript.
This project takes two numbers from the user and calculates their difference.

## 🌐 Live Demo

👉 **[Open Subtraction Calculator](https://basim-27.github.io/subtration-calculator/)**

## 📌 About The Project

This is a beginner-friendly JavaScript project created to practice:

* User input with `prompt()`
* Converting input into numbers
* Variables
* Arithmetic operators
* Subtraction
* Displaying results with `alert()`

## 🛠️ Technologies Used

* 🟠 HTML5
* 🟨 JavaScript

## ⚙️ How It Works

1. The user enters the first number.
2. The user enters the second number.
3. JavaScript subtracts the second number from the first.
4. The result is displayed using an alert box.

### Example

```text
Enter the first number: 20
Enter the second number: 8

The result of subtraction is: 12
```
